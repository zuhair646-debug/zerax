## 🎯 سيناريو الاستخدام (أنت كأب)

### 1️⃣ الدخول الأول

افتح: **https://zenrex.ai/s/zenrex-kids-pro#token=YOUR_TOKEN_HERE**

ولاش هذا اللحين، لأنه ما عندنا UI تسجيل دخول داخل الموقع المنشور. الحل المؤقت:
- سجّل دخول في **https://zenrex.ai** بحسابك (admin@zenrex.ai)
- افتح DevTools → Console → `localStorage.token`
- انسخ الـ token
- افتح **https://zenrex.ai/s/zenrex-kids-pro#token=الـtoken_اللي_نسخته**
- ستظهر رسالة "✅ تم تسجيل الدخول"

> 💡 الحل الأفضل (مستقبلاً): إضافة زر "🔑 ربط بحساب الأب" في الـ bot-page يفتح OAuth flow أو يستقبل token مباشرة.

---

### 2️⃣ كيف ترفع cookies (الخطوات الفعلية بالنص)

**خطوة 1: ثبّت Extension لتصدير الكوكيز**

في كروم/إيدج، ثبّت:
- **Get cookies.txt LOCALLY** (https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc)
- *لا تستخدم extensions مشبوهة — هذا هو الموثوق*

**خطوة 2: سجّل دخول في المنصة**

- افتح tiktok.com وسجّل بحسابك العادي  
- (نفس الشي ليوتيوب وانستقرام)

**خطوة 3: صدّر cookies.txt**

- اضغط أيقونة الـ extension (cookie 🍪 في شريط الأدوات)
- اضغط "Export"
- يحفظ ملف `tiktok.com_cookies.txt` في تنزيلاتك

**خطوة 4: ارفع للموقع**

- افتح zenrex-kids-pro → تاب البوت → اسحب للأسفل لـ "🍪 ربط حساباتك"
- في card TikTok: اضغط على input file → اختر الملف → اضغط "🔗 ربط الحساب"
- ستظهر toast خضراء: "✅ تم ربط TikTok"
- Badge في الـ card يتحول من "غير مربوط" إلى "✅ مربوط"

> ⚠️ لا ترفع cookies لحساب فيه معلوماتك المالية أو الخاصة. ينصح بإنشاء حساب TikTok ثانوي للأب فقط.

---

### 3️⃣ paste URL — الطريقة الأبسط

**شغّال الآن بدون أي إعدادات لـ YouTube:**

1. افتح يوتيوب على هاتفك
2. اضغط زر "مشاركة" → "نسخ الرابط"
3. ارجع لـ zenrex-kids-pro
4. تاب البوت → "🔗 إضافة فيديو يدوي"
5. الصق الرابط → اضغط "📥 حمّل وأضف للمراجعة"
6. انتظر 10-30 ثانية (حسب طول الفيديو)
7. الفيديو يدخل قائمة المراجعة 📥 أعلى الصفحة

**لـ TikTok/Instagram**: يحتاج cookies أولاً (راجع خطوة 2)

---

### 4️⃣ دور البوت الأوتوماتيكي — كيف يعمل؟

البوت **موقوف الآن** عمداً (بناءً على طلبك). لتشغيله:
- اضغط على badge "🤖 موقوف — اضغط للتشغيل اليدوي" في أعلى-يسار الصفحة
- يجلب 10 فيديوهات في كل نقرة (من Archive.org curated + reference samples)

**لتفعيل التشغيل التلقائي (كل 15 دقيقة)**: نحتاج patch صغير يعيد `setInterval(fetchBatch, 900000)`. لما تطلبه أضيفه.

---

### 5️⃣ تدريب البوت بعينات (Reference Samples)

**الفكرة**: تعطي البوت فيديو نموذج + وصف لكل فئة، يبحث عن مشابهات.

1. تاب البوت → "🎯 درّب البوت — أعطه عيّنات"
2. اختر فئة (قرآن مثلاً)
3. الصق رابط فيديو يعجبك في input الـ URL
4. اكتب وصف بالعربي: "قراءة هادئة بصوت طفل مع موسيقى خفيفة"
5. اضغط "💾 احفظ العينة"
6. البادج يتحول إلى "✅ محفوظ"

**ماذا يحصل بعدها؟** البوت لما يشتغل (يدوي أو تلقائي)، يستخدم وصفك كـ search query. مثلاً "قراءة هادئة بصوت طفل" يصير `query` في Archive.org.

---

### 6️⃣ قائمة المراجعة (Approval Queue) — هذي اللي تشتغل عليها يومياً

1. تاب البوت → القسم الأول "📥 الفيديوهات في انتظار المراجعة"
2. تشوف كل فيديو نزل (badge عدد بـ أحمر)
3. لكل فيديو:
   - **👁️ معاينة** → يفتح drawer يلعب الفيديو فعلياً داخل الموقع
   - **✅ موافقة** → الفيديو يظهر للأطفال فوراً في صفحة الـ Home
   - **🗑️ حذف نهائي** → يختفي + يضاف لـ blacklist (البوت ما يرجع يحمله أبداً)
4. إذا ما عملت شي خلال 24 ساعة → الفيديو يُعرض تلقائياً للأطفال

## 🎯 الميزات القادمة (حسب طلبك السابق)

### Phase A — هيكلية حسابات الأب/الأبناء
- حساب الأب: لوحة تحكم كاملة (إضافة فيديوهات، إعدادات، استعراض)
- حسابات الأبناء: متلقّين فقط، لا لوحة، لا تعديل
- نظام صلاحيات: child role vs parent role

### Phase B — قسم المكافآت
- الطفل يصلي → نقاط
- الطفل يكمل فيديو → نقاط
- الأب يحدد قيمة النقطة (1 نقطة = X ريال)
- آخر الشهر: تجميع نقاط → مكافأة مالية
- لوحة إحصائيات للأهل: كم نقطة جمع الطفل، كم صلاة، كم فيديو

### Phase C — قنوات مخصصة (Channel Whitelist)
- الأب يضيف قنوات Archive.org/YouTube موثوقة
- البوت يبحث **فقط** داخل هذه القنوات
- مثلاً: قائمة قراء قرآن مشهورين، أو قنوات BabyBus العربية فقط
